# Creator Production

Check project state, render_draft scope, exact script/storyboard IDs and host capability. Use [local renderer](references/local-renderer.md) only for the bundled queue adapter; other adapters need their own tested contracts before advertising them.

Produce versioned outputs by stage. Reuse work only if inputs, config and adapter version match and files remain valid. A render failure is not a reason to regenerate unrelated research/audio/images. Reconcile uncertain external acceptance before retrying paid/publishing operations.

Prefer code-native visuals when they fit the idea. Dev work is limited to the required renderer, not a new app. Missing tools/providers are explicit gaps; continue independent authorized work without buying or silently switching services.

Register artifact hashes/lineage and return media paths, manifest, measured technical checks and limitations. Decodable video does not prove story, legibility or audio quality; label silent demos. Pass drafts to Review/PM. v0 does not implement publication, channel creation, analytics or schedules; helper guards are not a sandbox against arbitrary external commands.
