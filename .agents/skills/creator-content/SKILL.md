# Creator Content

Read the project packet, exact plan and relevant research. Confirm write_content is in scope before production writing. Preserve audience, promise, format and language; material changes return to PM.

Build a clear hook, progression and payoff. Link important facts to sources, distinguish analogy from fact and do not conceal uncertainty. Storyboard meaningful scenes with narration, approximate timing, screen text and supported visual intent. Use [packaging](references/packaging.md) for format, SEO and revisions.

For the limited bundled renderer, use contracts/render-script.schema.json; it draws queues, not arbitrary video. Choose a suitable adapter instead of misrepresenting its capability.

Save each revision as a new artifacts/ file, register script/storyboard/metadata with input IDs, and preserve lineage. Return refs, creative choices, sourced claims and checks needed. A finished script is not automatically QA-passed or authorized to publish. After feedback, repair findings and affected dependencies rather than blindly rewriting everything.
