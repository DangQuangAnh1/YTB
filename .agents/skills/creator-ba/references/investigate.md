# Research a chosen idea

Read the brief, relevant decisions and sources only. Clarify audience, promise, format/length, language, originality, cost/tool constraints and the decision to make. Ask only uncertainties that materially change the plan while doing independent authorized research.

Prefer primary sources. Link important factual claims to supporting passages/metrics, not just a source list. Separate observation, inference and hypothesis, keep contradictions and access limits. A title/snippet does not prove the source video's content. Public competitor data does not reveal private CTR or retention.

Return a plan with viewer benefit, competitor observations, distinct angle, story/visual strategy, tools verified in the host, task outputs, acceptance and small test. A GitHub feature list is not local capability. Save full notes externally; return concise findings plus paths/URLs. Reuse stable sources; refresh trends, access, prices and policies when the decision depends on current conditions.
