# User feedback: one voice per character (2026-10-18)

After the format v2 trial (release-07-v2, artifacts A-172–A-174), the user wrote in chat:

> cũng ổn ổn, góp ý 1 cái là với các video có nhiều text hay nhiều nhân vật tôi thấy mấy kênh kia kiểu mỗi nhân vật 1 giọng đọc., nghiên cứu, tổng hợp, tham khảo và xuất 1 video sửa lại nhé

Interpretation:
- Format v2 is provisionally accepted ("cũng ổn ổn"). This is not acceptance for publishing.
- **New rule for P-1:** when a video has several characters or a lot of text, each character gets its own voice: the poster, each commenter, and people quoted in the post such as "bố nhắn …". A narrator voice reads the short bridge asides. The same handle keeps the same voice throughout the video.
- The user asked for research (research/multi-voice-v1.md, BA role) and a revised export of the same story.

Scope:
- Use only the local VieNeu built-in presets. No paid providers and no cloning of real people's voices.
- Voice gender and region are chosen from cues in the text. When the text gives none, the choice is a creative guess and is recorded as such.
- Human listening is still needed. Earlier lesson (tasks/lesson-voice-audition-first.md): voice fit is the user's call.
