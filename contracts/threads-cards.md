# Threads cards adapter — threads-cards-1

`scripts/render_threads.py` is a local, no-network draft renderer. It does not publish or update STATE. Register returned outputs with `agency.py artifact` and expected revisions.

Inputs: a registered JSON script (`kind=script`) and registered storyboard (`kind=storyboard`) from the current plan. Rendering requires current `render_draft` authorization, expected state revision, intact input hashes, and the pinned VAIS-1000 preset hash. The script contract is validated in `contract()`; it supports 4–10 scenes, exactly two narration beats and two diagram labels per scene, Vietnamese only, and the six original diagram kinds listed in code.

Runtime: create a Python 3.12 venv outside the repository and install `scripts/threads-runtime-requirements.txt` from PyPI. The host's bundled Python can create the venv when system Python lacks ensurepip. Download the model/config/model card from the revision recorded in P-1 research; retain them outside Git. Confirm licenses for a new use/project; the software package license and model/dataset license are separate.

Example for the current approved P-1 inputs (refresh state revision with resume first):

```sh
/path/to/venv/bin/python scripts/render_threads.py P-1 --script-id A-014 --storyboard-id A-015 --expected-revision CURRENT --voice-dir /path/to/vais1000-medium
```

Outputs: unique `artifacts/render/threads-<id>/` containing PCM narration, H264/AAC MP4 1080×1920/30fps, per-beat WAVs and source frames, manifest with hashes/timings/versions, layout counts, audio metrics and full decoder log. Narration padding is rounded to frames (735 samples/frame at 22.05kHz), captions share those same boundaries. The measured video must be 45–75 seconds; out-of-range speech fails before video encoding rather than stretching/cutting it silently. Encoded audio is 48kHz. Full decode and no PCM clipping are technical checks; human listening and content QA remain separate.

Private/source raw media and model files stay ignored/outside Git. Media outputs are recoverable from the exact script, storyboard, adapter snapshot, voice/config hashes and runtime versions; speech noise may make regenerated bytes differ. Do not claim deterministic byte reproduction. Contact sheet covers both beats of every scene; it cannot prove transitions or audio quality.

P-1 provenance/rights: `research/session-01-source-and-tools-v1.md`, source/credits in `artifacts/content/draft-01-metadata-v1.md`. `tasks/adapter-contract-checks-v1.json` records rejection tests. Reuse in later pilots requires matching approved plan and valid sources/assets.
